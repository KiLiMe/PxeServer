# 桌面界面与配置

原生界面由 `github.com/egoist/mygo` 绘制，无需 Node / WebView2。

## 七个选项卡

| 页 | 内容 |
| --- | --- |
| 主页 | 服务开关（ProxyDHCP / HTTPd）、根目录与 HTTP 端口、网卡与 IP、DHCP 地址池、启动文件与高级选项、调试接口地址 |
| 租约 | 当前 DHCP 租约表 |
| 启动菜单 | 菜单脚本编辑器 + 文件名下拉 + 重新载入 / 保存 / 用默认程序打开 |
| 架构 | Option 93 架构 → 启动文件映射 |
| 日志 | 环形 500 行，按来源着色，「只看故障线索」筛选 `W`/`E`，支持导出 |
| 设置 | 界面语言（`zh-Hans` / `en` / 跟随系统）、防火墙放行与状态（仅 Windows，其它平台整段不显示） |
| 关于 | 版本与依赖信息 |

顶部含状态徽章、启动 / 停止 / 保存配置按钮（有未保存改动时显示 `● 未保存`）；操作结果以底部浮层（Toast）提示。

主页「启动与 DHCP 选项」还包含：Option 17 根路径、Option 60 ClassID、Option 66/67 覆盖值、Option 252、额外选项、Option 43 子项 1、EFI 不发 Option 43、自动启动服务。

## 网卡选择

主页「网卡」下拉列出本机所有 IPv4 网卡（含未插网线的适配器，标注「未连接」），启动时按当前 `server_ip` 自动对齐。选中后自动填充服务器 IP（Option 54）、子网掩码、广播地址，Next-Server 为空时跟随，IP 池起始跨网段时自动调整为 `.2`。保留项「（手动填写 IP）」允许自由手改而不被覆盖。

## 防火墙放行

Windows 绑定 67/69 无需管理员权限，但入站流量需放行防火墙。「设置 → 放行程序」按**程序路径**添加一条入站 Allow 规则（`-Program <exe 路径>`、`-Protocol Any`，规则名 `PXE Server（程序路径放行）`），换端口无需重加；非管理员时会触发 UAC 提权执行 `PxeServer.exe -firewall-apply` 后退出。

- 状态显示：管理员进程实时查询规则；普通权限按 `config.json` 中 `runtime.firewall_exe` 是否匹配当前程序路径判断。「撤销放行」删除规则并清除该标记。
- **移动过程序位置**：规则仍指着旧路径，状态会变成「未放行」，并在下面补一句「程序已移动（原路径 …），请重新放行」。再点一次「放行程序」会先删同名旧规则、按新路径重建，不会留下重复规则。

**非 Windows 没有这一段**：Linux 的防火墙按端口而不是按程序管理（ufw / firewalld / nftables 各有各的写法），一键「放行程序」没有对应概念，所以整个区块不画（`internal/firewall` 的 `Supported()` 为假），需要的端口自己开，见 [troubleshooting.md](troubleshooting.md)。

## 单实例

同一登录会话只允许一个界面实例：第二次启动抢不到单实例锁（Windows 是命名互斥体 `Local\PXE Server`，Linux 是 `runtime_dir/pxe-server.lock` 上的 `flock`），程序把已在运行的窗口拉到前台后立即退出，不会去抢 67/69/80 端口，也不会出现两份进程互相覆盖 `config.json`。Linux 侧不做窗口激活（没有通用的 X11/Wayland 接口），退化为一句话提示「已有一个 PXE 启动服务器在运行。」。命令行版 `pxed` 没有这个限制，多开时直接在端口绑定上失败。

## 额外 DHCP 选项

语法 `code[.sub]=值`，多项以 `;`、`,` 或换行分隔；值支持 `ip:1.2.3.4`（可省略 `ip:`）、`str:文本`、`hex:0102`（允许空格）、`u8:3` / `u16:3600` / `u32:7200`。带 `.sub` 时编码为子选项（`子选项号 + 长度 + 值`），同 `code` 自动拼接。

例：`175.6=ip:1.8.1.1; 175.8=ip:192.168.5.1`（联想/惠普常用）。

- 额外选项在应答末尾写入，可覆盖标准选项，但禁止覆盖 `52`、`53`、`54`。
- **Option 43 子项 1 = 0.0.0.0**：勾选后在 Option 43 头部追加 `01 04 00 00 00 00`（部分老式 BIOS 网卡需要）。

## 运行日志与运行态

日志同时写入 exe 同目录 `PXE-server.log`（超 2 MB 轮转 `.log.old`），单行记录「请求 → 应答」，5 秒内同 MAC 同类重复请求合并计数（`（同 MAC 第 N 次）`）。

运行态信息写入 `config.json` 的 `runtime` 段：

```json
"runtime": { "debug_addr": "127.0.0.1:18080", "firewall_exe": "C:\\Program Files\\PxeServer\\PxeServer.exe" }
```
